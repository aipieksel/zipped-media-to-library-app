# Folio PNG to SVG — acceptance checklist

- [ ] R1 — Integrate the converter with clear navigation and preserve the library UI and state.
- [ ] R2 — Generate editable pixel geometry and merge identical adjacent pixels.
- [ ] R3 — Preserve native dimensions, transparency and antialiased edge pixels.
- [ ] R4 — Add clearly labeled embedded-PNG mode using the original bytes.
- [ ] R5 — Support responsive drag-and-drop batch processing with useful error states.
- [ ] R6 — Show original and SVG previews, including native-size viewing.
- [ ] R7 — Provide individual and ZIP downloads with safe, collision-free filenames.
- [ ] R8 — Keep conversion files on the device and out of the source repository.
- [ ] R9 — Verify the rendered SVG and show either zero differences or the differing-pixel count.
- [ ] R10 — Test opaque, transparent, partial-alpha, antialiased, palette and multicolor PNGs.
- [ ] R11 — Explain pixel-grid scaling and the limits of browser and color-profile verification.
- [ ] R12 — Complete the reviewed plan and independent verification.
- [ ] R13 — Commit and push meaningful milestones.
- [ ] R14 — Publish the verified app to the existing private site.
