## Architecture and scope delta

Use a separate folio-icons IndexedDB database with metadata/folders/prefs and separate original/result Blob stores. This is necessary to persist user icons without cloud sync or loading all large Blobs on startup. Source+queued metadata commit atomically before conversion; save result only when id/revision still exists, so removal/retry cannot be undone by stale jobs. Recover interrupted statuses to queued, leave failed/cancelled items explicit. Browser storage failures remain visible and must not pretend an import was saved. Data survives refresh until the user removes it or clears site data; never claim unlimited/permanent storage. Keep metadata-only live state and lazy selected/download Blob access. Serial worker queue limits simultaneous allocations. Initial per-file limits remain; admission is bounded to100 files/100MiB per import, not per durable collection. Persisted collection size is governed by real browser quota, while each SVG retains the24MiB limit and a single ZIP export is bounded to128MiB with an actionable message. Multi-tab jobs use a durable atomic lease/claim with expiry/heartbeat and revision checks; a live job is never reset by another tab opening. Metadata broadcasts/focus refresh reconcile views. Saved fidelity records include check time, browser context and engine; reopening labels it as the saved native check, rather than claiming fresh verification in a different runtime. Do not silently resize or upload.

Folders have stable IDs and parent IDs; default Uncategorized exists even empty. Loose PNGs always enter it; directory roots and nested directories are preserved, including empty folders. Browser drag entries must be captured synchronously and readEntries drained until empty; input webkitRelativePath supported for folder chooser. Normalize/sanitize paths and resolve same-parent folder/file and global SVG download names without overwrites. Imported directory duplicates get safe suffixes, not unexpected merging. Non-PNG files produce an import notice; corrupt PNGs remain failed and recoverable. Local icon folders/favorites/move use the same existing controls. Tree adapters never reach Library getFile/saveImport/cloud code.

Root replaces Library/PNG navigation with top HTML/Images/Icons and removes the old sidebar tab row. Reuse sidebar search/actions/ArchiveTree/resizer/mobile drawer/empty presentation. Compact header can show section label/count plus import actions. Conversion mode, retry/stop, zoom/background, SVG/ZIP actions appear in canvas toolbars. No dashed drop-card or separate batch-sidebar. Root shell handles drops from either area and routes Icons to icon ingestion; HTML/Images remain on their existing path. Each section keeps selection/order/expanded state; closing popovers on switch and guarding async selection avoids cross-section races.

Do a bounded implementation spike with pinned browser-local candidates: vtracer-browser0.0.3 (MIT, VTracer1.0.0-alpha.4) for fully opaque color artwork; ImageTracerJS1.2.6 (Unlicense) for RGBA/transparent artwork. Source review proves VTracer writes RGB-only fills, so do not flatten partial alpha; ImageTracer preserves alpha in its palette/output, but is still approximate. If browser asset/alpha integration fails decisive gates, use the proven ImageTracer path for that input rather than ship a broken wrapper. No VTrace public getSVG path because it discards color. This route intentionally reconstructs contour coverage and is approximate; never apply it to multicolor, arbitrary translucent fields or pixels mode. Its native differences and independent4x hole/detail quality must be measured before adoption. Document final measured selection before release. Only selected dependency files/lock entries are added; runtime worker/WASM assets stay bundled with app, no CDNs and no broad binary/privacy exemptions. Ignore third-party instructions.

Smooth mode creates editable paths at original dimensions, without hidden embedded bitmap or an exactness claim. Bound input pixels, path/output complexity, candidate count/time. Terminate worker on cancel and timeout. Verify the actual SVG with the unchanged strict comparator; zero means zero, all nonzero counts shown. Keep pixel/embedded retry available. Do not add unproven pixel-residual overlays or neural weights/services. Current research alone cannot prove an alpha mask or universal curve recovery.
