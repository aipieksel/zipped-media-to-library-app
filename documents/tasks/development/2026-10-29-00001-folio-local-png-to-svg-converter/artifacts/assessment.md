## Toolchain and relevant verification

- `npm run test`: privacy pretest, then Node tests through `tsx` over `tests/*.test.ts`. Existing tests exercise archive import, tree/favorites, folder selection, ordering, dimensions, grids, component rendering, cloud data and Google Drive boundaries.
- `npm run build`: privacy prebuild, generated capture script, `tsc -b`, Vite build and existing Worker package. It is a full deployment build; root should run once source is stable.
- `npm run check:privacy`: staged Git index scan, required before every commit or source transfer by repository policy.
- `npm run dev`: capture-bundle preparation followed by Vite on `0.0.0.0`. Local dev does not provide private production collection APIs unless the preview harness supplies them, so an existing collection loading error in local preview must not be mislabeled a converter failure.
- No lint script, Playwright package, jsdom or testing-library is configured. Match existing test convention rather than adding a new suite merely for minor markup.
