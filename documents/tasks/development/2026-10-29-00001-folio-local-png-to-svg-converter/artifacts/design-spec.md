# UI specification — revision 1

Owner: /root. Observed baseline: existing app at http://terminal.local:4173/ using the exact GitHub source matching Sites 05766c8. Rendered 1363×936 through CUA. Live private URL showed an authentication gate in the separate browser; no private collection content was inspected. Source comparison confirmed App.tsx, styles.css and worker/cloud.mjs equal the published-source checkout.

Keep the existing compact white/gray Folio layout, system font, orange --accent, --line borders, 4–7px radii and 10–12px utility text. No new branding, palette or UI framework. A 34px navigation strip above both workspaces contains Library and PNG to SVG with icons and an active state. Library retains its sidebar, toolbar, tabs, data/selection and existing handlers. Shared native buttons/selects use existing classes.

Converter component owns transient files, queue, selected item and progress. Desktop: compact file-queue sidebar (roughly 260–300px) with Add PNGs and clear/remove controls, conversion-mode native select and concise local-only status. Main area: 40px toolbar with selected filename, source dimensions, download SVG and ZIP controls; two equal checkerboard previews labeled Original PNG and SVG output; Fit/100%/enlarged zoom and checkerboard/light/dark background controls. Default mode pixel vectors. Result details show dimensions, source/output bytes, rectangle count, mode and exact pixel-check state. Empty state modest centered upload affordance, not a branded landing page. Mobile ≤650px: queue above previews, comparisons stacked, actions wrap, no viewport-wide overflow; the global workspace navigation remains visible.

Mode control sets the mode for new imports. A selected-item retry/reconvert action explicitly applies the chosen mode to an existing file. Never silently replace pixel vectors with embedded bitmap. Oversized vector items retain their original and offer explicit embedded conversion. Batch processing is serial with per-file queued/converting/verifying/ready/error/cancelled states. Cancellation/removal must not leave stale completed results; switching workspaces preserves in-session results and does not pass files to library import. Data remains in memory until removed/reload; tell users to download before closing.

Accessibility: native controls, persistent labels, aria-pressed navigation buttons or tabs with complete keyboard model, labeled queue item selection, native keyboard select behavior, polite progress/fidelity status, useful disabled states. Hidden workspace content is not tabbable. Collection global shortcuts are inactive while converter is active. Cancel stops work; no surprising focus trap. Compare preview fit does not alter output/verification dimensions. Avoid falsely announcing matches before checking.

Displayed limitation: pixel vectors retain the pixel grid when enlarged; this is not curve tracing. Verified means exact visible RGBA in this browser at native dimensions using sRGB canvas; other browsers/profiles are not certified. Embedded PNG is labeled bitmap inside SVG, not editable vector artwork.
